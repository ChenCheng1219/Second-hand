# Second-Hand Campus Trading Platform

## Project Description
This is a second-hand trading platform designed specifically for university students. It allows students to buy and sell used items such as textbooks, electronics, dormitory supplies, and daily necessities within the campus community.

## Technologies Used
- **Backend:** Python Flask
- **Database:** Microsoft SQL Server
- **Frontend:** HTML5, CSS3, JavaScript
- **Version Control:** Git / GitHub

## Features
- User registration and login
- Post items with images
- Search and filter by category
- Chat between buyers and sellers
- Order tracking (items bought and sold)
- Campus floor map for pickup locations

## How to Run the Project (Optional)
1. Clone the repository
2. Install dependencies: `pip install flask pyodbc`
3. Set up SQL Server database using the provided schema
4. Run `python app.py`
5. Open `http://127.0.0.1:5000` in your browser
